Blue Team Agent

Defending the system

Problem

The backend agent needed protection from malicious or malformed input.

Architecture

Two-layer design — a free "Precheck" agent (regex, ClamAV, YARA, nmap, dependency audits) that runs on every interaction, escalating to a paid LLM-based "Advanced" agent only when something's ambiguous.

My Role

Designed the tiered architecture and built the Precheck layer in n8n.

Outcome

Passes penetration testing and can be integrated with any client we take on.
